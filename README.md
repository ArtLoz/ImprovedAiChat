# AI Chat

AI Chat is an Android application for chatting with various AI models. Currently, it supports DeepSeek and Qwen Max.

## 🔧 Installation and Setup

1. **Clone the repository**:

   ```sh
   git clone https://github.com/ArtLoz/ImprovedAiChat.git cd android-ai-chat
   ```

2. **Add `google-services.json`**:

   - Obtain `google-services.json` from Firebase Console.
   - Place it in the `app/` directory.

3. **Build and run the project**:

   - Open the project in Android Studio.
   - Sync dependencies (`Sync Gradle`).
   - Run the application on a device or emulator.

## 🚀 Features

- Support for DeepSeek and Qwen Max models.
